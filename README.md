# Манипулятор типа М20П. Кинематика, динамика, кправление и планирование траектории

Проект представляет из себя серию курсовых проектов, реализующих полную модель и пайплайн управления цилиндрическим манипулятором М20П, со 6 степенями свободы.
Манипулятор состоит из вращательного шарнира, двух линейных приводов и сферического запястья.

## Блокноты

| # | Notebook | Topics |
|---|----------|--------|
| 1 | [RoboticsPart1.ipynb](RoboticsPart1.ipynb) | Таблица Денавита-Хартенберга, прямая и обратная кинематика, аналитический якобиан, численный якобиан, анализ и решение сингулярностей с помощью демпфированнаго метода наименьших квадратов и оптимизации манипулятивности в нулевом пространстве |
| 2 | [RoboticsPart3.ipynb](RoboticsPart2.ipynb) | Планировка траекторий. Трапецеидальные профили скоростей, полиномиальные траектории, прямолинейные движения в картезианском пространстве через интерполяцию IK и через псевдообратный якобиан |
| 3 | [RoboticsPart3.ipynb](RoboticsPart3.ipynb) | Симуляция с учётом физической модели робота. Символьный вывод динамики по Лагранжу, вычисление моментов для управления с PD-регулятором |
